# Chronicle Sidekick Bridge - WoTLK

A dedicated SavedVariables handoff for the Chronicle Sidekick desktop app.
Built for WoW **3.3.5a**. Storage only; producer-addon integration is required.

## Install

Place the addon in `Interface/AddOns/ChronicleSidekickBridgeWoTLK/`, enable it,
then log in and `/reload` to create its data file.
